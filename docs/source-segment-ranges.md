# 编辑源视频分段范围

适用于 v2v / rv2v 源视频时间轴。拖动青色中间分割线，可调整相邻两段
的边界；释放鼠标后保存。

界面从第 1 帧计数，普通段落采用左闭右开区间，例如 `[1,159)` 后接
`[159,318)`：第 159 帧属于后一段，前一段实际包含第 1–158 帧。
最后一段使用闭区间，例如 `[318,400]`，包含视频最后的第 400 帧。
片段说明同时写明包含起始帧、是否包含结束帧，以及实际帧数和时长。
内部 JSON 继续使用从 0 开始的 start + length，兼容已有工作流。
修改范围保留两侧分段的 ID、提示词、素材、LoRA 和运行选择。
每段至少保留 4 帧；视频首尾、上传多个视频的素材接缝固定。
拖动会限制在相邻段内。
